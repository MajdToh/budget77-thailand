# งบประมาณรายจังหวัด 77 จังหวัด ปี 2570

Interactive Dashboard สำหรับสำรวจและเปรียบเทียบงบประมาณรายจังหวัดทั่วประเทศ

นำเสนอข้อมูล 77 จังหวัด แยกตาม 9 หมวดหลัก เพื่อช่วยให้ประชาชนสามารถมองเห็นภาพรวม เปรียบเทียบโครงสร้างงบประมาณระหว่างจังหวัด และสำรวจรายละเอียดของจังหวัดที่สนใจได้ง่ายขึ้น

## สิ่งที่ดูได้

* ภาพรวมงบประมาณ 77 จังหวัด
* เปรียบเทียบสัดส่วนงบประมาณ 9 หมวด
* Heatmap เปรียบเทียบทุกจังหวัด
* Stacked Bar เปรียบเทียบโครงสร้างงบ
* เลือกจังหวัดเพื่อดูรายละเอียด
* ดาวน์โหลดข้อมูลที่เผยแพร่ประกอบ Dashboard

## การใช้งาน

เปิด Dashboard ผ่านเว็บไซต์ แล้วเลือกจังหวัดหรือรูปแบบการเปรียบเทียบที่ต้องการ

ข้อมูลใน Dashboard จัดทำขึ้นเพื่อช่วยให้ประชาชนเข้าถึงและทำความเข้าใจข้อมูลงบประมาณได้ง่ายขึ้น

## หมายเหตุ

ตัวเลขที่แสดงเป็นข้อมูลที่สามารถระบุการจัดสรรในระดับจังหวัดได้ตามหลักเกณฑ์การจัดทำฐานข้อมูลของโครงการ

ข้อมูลบางประเภทที่ไม่สามารถระบุเป็นงบของจังหวัดใดจังหวัดหนึ่งโดยตรง อาจไม่ได้รวมอยู่ในยอดรายจังหวัด
